# Проверка кейсов 2026

Статическая страница для ручного прохождения сценариев на edudev.

Открыть: https://averjahn.github.io/med-game-2026-review/

Одиночный щелчок по заданию раскрывает шаги: слева текст до правки, справа предложение по документу. Двойной щелчок открывает прохождение.

Токен игрока хранится только в `localStorage` браузера, в репозиторий не попадает.
