Проверка кейсов

Одиночный щелчок раскрывает шаги: слева состояние до правки, справа предложение по документу. Двойной щелчок открывает кейс: is_platform=true, group_id=13, course_id=126. Вручную подтверждено только задание 2.

Галочка «Утвердить» сохраняется в этом браузере. Двойной щелчок по заголовку открывает прохождение.
